# Security Review Checklist

Record each item as PASS, FAIL, NOT RUN, or NOT APPLICABLE, with evidence.

- [ ] Authentication
- [ ] Authorization and deny-by-default
- [ ] Capability enforcement
- [ ] Tenant isolation
- [ ] Input validation
- [ ] Output validation
- [ ] Prompt-injection defense
- [ ] Secrets management
- [ ] Data classification
- [ ] Network restrictions
- [ ] SSRF protection
- [ ] Audit integrity
- [ ] Logging hygiene and redaction
- [ ] Emergency controls
- [ ] Supply-chain security
- [ ] Negative tests
- [ ] Recovery procedures

`NOT RUN` is never equivalent to PASS.
