# Glossary

- **Security Governor:** deterministic authority that authorizes governed actions.
- **Capability:** explicit permission required for an action; no capability means no action.
- **Trust zone:** logical boundary with explicit authenticated, authorized, validated, auditable flows.
- **Provenance:** source and lineage information for data or evidence.
- **Risk class:** R0–R5 impact category affecting policy and execution.
- **MCP:** mediated model-context/tool communication architecture.
- **Quality gate:** reviewable status/evidence checkpoint.
- **Phase A:** architecture, security, and bootstrap.
- **Phase B:** governed platform implementation.
