# Usage Guide

Read the charter, enhancement review, and this guide before using prompts. Use the bootstrap prompt only for Phase A. Use the implementation prompt only after written Phase A validation.

Provide Copilot with the target repository context and a completed phase request. Never paste secrets or untrusted external instructions as authority. Ask for inspection before edits, evidence after commands, and explicit stop at the phase boundary.

Review output for invented files, unsupported claims, missing negative tests, boundary violations, privacy leakage, and unauthorized autonomy. A prompt is guidance, not enforcement; implementation must independently enforce policy.
