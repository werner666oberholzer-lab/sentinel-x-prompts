# Prompt Customization Guide

Customize repository paths, approved dependencies, environments, owners, risk thresholds, and operational commands only when repository evidence supports the change. Preserve the authority model, deny-by-default behavior, trust zones, data classes, risk classes, approval requirements, anti-hallucination vocabulary, and stop conditions.

Document deviations in an ADR. Do not add secrets or confidential examples. If a requirement is not applicable, state why and record the decision rather than deleting it.
