# Execution Sequence

1. Inspect target repository and instructions.
2. Read charter and enhancement review.
3. Execute Phase A bootstrap prompt.
4. Review architecture, threats, ADRs, and proposed changes.
5. Run bootstrap gates; stop if any required gate fails or is NOT RUN.
6. Commit Phase A separately.
7. Prepare one Phase B execution request.
8. Execute one coherent implementation phase.
9. Review code, tests, security, privacy, audit, and residual risk.
10. Record completion and approve the next phase explicitly.

Emergency controls must remain usable without AI services.
